## IntelliTest: A New Approach to Android UI Testing with ChatGPT & Appium Automation

IntelliTest is an innovative test automation framework that leverages the capabilities of ChatGPT with Visual input (ChatGPT4-V) and traditional ChatGPT models to interpret user intentions expressed in natural language and execute corresponding actions on an Android device. The framework consists of a Node.js controller utilizing WebDriver.io as an Appium client.

For more details see [Project Report](https://github.com/user-attachments/files/20024054/CMPE_492_Project_Report_2018400141.pdf)
